Положите сюда файлы шрифтов (имена важны):

Kontrabanda.woff2   (или .woff / .ttf / .otf) — заголовок «Web designer»
CenturyGothic.woff2 / CenturyGothic.ttf        — основной, обычный
CenturyGothic-Bold.woff2 / CenturyGothic-Bold.ttf — основной, жирный

Если файлов нет: Century Gothic берётся из системы (Windows, macOS с Office),
иначе подставляется похожий Didact Gothic.
Century Gothic — платный шрифт Monotype: для веба нужна веб-лицензия.
